# ROBO MYSTERY

Persoonlijk verjaardagsspel voor Wannes (12): een goocheltrucs-mysterie in een handgemaakte speelgoedwereld. Wannes bestuurt de robot en komt aan het einde bij zijn eigen verjaardagsfeest.

## Huidige fase
We werken eerst het volledige ontwerpdossier uit. **Er wordt nog geen code ontwikkeld of aangepast als onderdeel van deze fase.** Zodra het dossier af is, wordt het spel met één uitgebreide bouwopdracht (master-prompt) gemaakt, gevolgd door één ronde fixes na testen op een iPhone.

## Belangrijke uitgangspunten
- De originele ROBO MYSTERY-referenties zijn leidend.
- Beeldtaal: retro-futuristische sciencefiction met handgedrukte jarenzeventig-popart; textuur sterk en verweerd.
- De interface is onderdeel van dezelfde vintage posterwereld.
- Mobile-first, speelbaar in de browser, geen account, gratis op GitHub Pages.
- Alle spelertekst is in het Nederlands en staat als echte tekst (niet in afbeeldingen).
- Nieuwe ontwerpen worden niet automatisch als definitief beschouwd; zie `docs/DECISIONS.md`.

## Nog niet bouwen
De gamecode wordt pas aangepakt nadat spelconcept, uitdagingen, assets en techniekregels voldoende zijn vastgelegd. Het bestaande `index.html` is een eerste prototype dat een ander verhaal volgt; de status ervan staat in `docs/DECISIONS.md`.
